See any pack for yourself

Run any uitoolkit app in a pack with one environment variable, or render every control in every state. Every pack is drawn by an engine, the Java looks included (Metal and Nimbus, rewritten clean-room from published facts); the skins are drawn from pictures the repo generates. This page is rebuilt by tools/atlas.

# any app, any pack
UITK_THEME=cde go run ./examples/mail
# every scripted gallery shot in one pack
go run ./examples/gallery -screenshot /tmp/shots -theme luna
# every control in every state, every pack
go run ./cmd/uitk-themesheet -all -o /tmp/sheets
# the pack list this page was built from
go run ./cmd/uitk-themesheet -list
# this page, every image on it, and the README sheets
tools/atlas/render.sh && tools/atlas/build.py && tools/atlas/sheets.sh
